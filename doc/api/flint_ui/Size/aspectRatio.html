aspectRatio property

double get aspectRatio

The aspect ratio of this size (width / height).

Implementation

double get aspectRatio {
  if (height != 0.0) return width / height;
  if (width > 0.0) return double.infinity;
  if (width < 0.0) return double.negativeInfinity;
  return 0.0;
}
